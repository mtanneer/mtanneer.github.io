After multiple failed attempts finding a perfect template, I resorted to making my own.
Started as a superlight static site built with plain HTML, CSS and JavaScript — no
frameworks, no build step — then rebuilt with Astro to add a git-backed blog, a contact
form, and live GitHub stats while staying on GitHub Pages at zero cost.
